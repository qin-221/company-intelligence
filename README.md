# Company Intelligence｜面试企业研究助手

一个用于面试准备的 Codex Skill：帮助求职者快速看懂目标公司的业务、商业模式、经营状况、组织与人才特点，以及目标岗位为什么存在、创造什么价值。研究尽量可靠，表达保持简洁、清楚、通俗。

## 能做什么

- 快速了解公司做什么、客户是谁、如何赚钱，以及竞争位置。
- 通过商业模式画布梳理业务逻辑。
- 结合招聘 JD，从公司业务反推岗位职责、产出和能力要求。
- 评估职业价值、企业和岗位风险，并生成面试准备建议。
- 按需进行快速研究或深度研究；默认先给一页式结论。

## 安装

将 company-intelligence 文件夹复制到 Codex 的技能目录：

    ~/.codex/skills/company-intelligence/

Windows 常见位置：

    %USERPROFILE%\.codex\skills\company-intelligence\

保留整个文件夹结构，至少包括 SKILL.md；参考框架和报告模板用于深度研究。

## 使用示例

- “帮我快速研究一下宁德时代，我面试供应链计划岗位。”
- “根据这份 JD 深度分析这家公司和岗位，并给我面试策略：…… ”
- “我在考虑这家公司是否值得加入，重点帮我看经营风险、团队风格和岗位成长性。”

提供岗位 JD、个人经历和关注点可以让岗位分析更贴合；这些信息均为可选。默认先进行快速研究，用户要求深入时再展开。

## 研究原则

- 优先使用公司官网、财报/监管文件、政府登记和官方招聘信息等一手来源。
- 重要信息交叉核实，说明来源和数据时间。
- 明确区分已证实事实、分析判断和待核实内容；不编造未公开数据。
- 员工评价只作有限参考，不以个别评论概括公司文化。
- 先说结论并解释意义，不堆砌术语或原始资料。
